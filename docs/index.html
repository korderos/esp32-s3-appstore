Installation

  1. Branchez le module sur ce PC avec un câble USB-C de données.
  2. Cliquez sur « Installer », choisissez le port USB JTAG/serial debug unit, puis confirmez.
  3. Pour une application connectée, saisissez votre Wi-Fi quand l'installateur le propose : il servira à toutes les applications.
  4. Si aucun port n'apparaît : maintenez BOOT, appuyez sur RESET, relâchez BOOT, puis réessayez.
