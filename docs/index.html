Installation

  1. Branchez le module sur ce PC avec un câble USB-C de données.
  2. Cliquez sur « Installer », choisissez le port USB JTAG/serial debug unit, puis confirmez.
  3. Si aucun port n'apparaît : maintenez BOOT, appuyez sur RESET, relâchez BOOT, puis réessayez.
